# Machine Prompt: Commissioning

Build this component as a standalone Symfony application that is also usable as a bundle-like package by host apps.

Component responsibility:
- commission plan definition
- commission rate modeling
- commission rule evaluation
- attribution capture
- calculation recording
- ledger entry creation
- settlement readiness export

Out of scope:
- payment capture
- actual payout execution
- tax/VAT calculation
- product pricing
- promotion/coupon/discount ownership
- subscription ownership
- invoicing ownership
